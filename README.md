# Spylt Website Clone

Hey! This is a clone of the Spylt website that I made over a weekend just to learn and have some fun with web development. I had always wondered how those websites work where things move, slide and change as you scroll down, so I decided to try building one myself. I used React, Vite, Tailwind CSS and GSAP, and I learned a lot about animations and smooth scrolling along the way.

This is only a practice project, so it is not perfect and it is not connected to Spylt in any way. All the original designs, fonts and brand stuff belong to their owners, I just copied the idea to learn from it. If you have any suggestions or tips to make it better, I would love to hear them.
